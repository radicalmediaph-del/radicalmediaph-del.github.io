# RadicalMediaPh — website

A static, multi-page site. No build step, no frameworks, no installs required.

## Two ways to open it

**1. Just look at it — `OPEN-WEBSITE.bat`**
Double-click it. The site opens in your browser straight from this folder.
Everything works this way: all pages, links, filters, forms, images.

**2. Run it on localhost — `start-server.bat`**
Double-click it. It tries, in order:

1. Python, if you have it installed → serves on <http://localhost:8000>
2. **Windows PowerShell** (already on every Windows PC — no install needed)
3. If both somehow fail, it just opens the site directly

Your browser opens automatically. Close the black window to stop the server.
Want a different port? Run `start-server.bat 8080`.

> If Windows shows a "Windows protected your PC" box the first time, click
> **More info → Run anyway**. That warning appears for any downloaded .bat file.

## How the forms work

**Every message is saved to your Google Sheet** — one row per submission, from
every form (contact, lead-gen strategy, ebook order), plus an email alert.

This needs a one-time, five-minute setup: **see `google-sheet/SETUP.md`**.
Until you do it, the forms still work — they just fall back (see below) instead
of saving a row.

If the sheet can't be reached for any reason, nothing is lost. The form shows
the visitor three ways to send the message straight to you:

- **Send by email** — opens their mail app, pre-filled and addressed to you
- **Send on WhatsApp** — opens WhatsApp with the message ready to send
- **Copy message** — copies it to the clipboard

The logic lives in `wireForms()` / `saveToSheet()` in `assets/js/main.js`.

## Taking payment

`payment.html` shows your GCash, Maya and bank details, and a form where the
buyer confirms what they sent. That confirmation goes to your Google Sheet and
your inbox like every other form, with the method, reference number and amount
in the Extra column.

**You must fill in your details for the page to work.** Open
`assets/js/main.js` and edit the `payment` block near the top:

```js
payment: {
  currency:   "PHP",
  ebookPrice: "499",
  gcash: { label: "GCash", name: "Your Name", number: "09XX XXX XXXX", qr: "" },
  maya:  { label: "Maya",  name: "Your Name", number: "09XX XXX XXXX", qr: "" },
  bank:  { label: "Bank Transfer", name: "Your Name", number: "1234567890", bank: "BPI" }
}
```

- A method with an empty `number` is hidden — add them one at a time if you like.
- Until at least one is filled in, the page tells visitors to message you instead,
  so it is never broken or misleading.
- **QR codes:** save the image into `assets/img/` and put the filename in `qr`,
  e.g. `qr: "assets/img/gcash-qr.jpg"`.
- The price shows on the ebook page and the payment page from `ebookPrice`.

This is a manual flow — you confirm each payment yourself. It costs nothing and
needs no merchant account. If you later want cards and automatic delivery, that
needs a provider like PayMongo, Stripe, Gumroad or Lemon Squeezy.

## Things to change before going live

1. **Social links.** Open `assets/js/main.js` and edit the `SITE` object at the
   top. It supports Facebook, Instagram, TikTok, YouTube, LinkedIn, X, Threads,
   Telegram and Viber. Paste your real profile URL next to each one you use and
   leave the rest as `""` — empty ones are simply not shown. The icons appear in
   the footer of every page and in the "Follow Me" row on the contact page, so
   one edit updates the whole site. Email, phone and WhatsApp live in the same
   place and are already correct.

2. **Portfolio images.** Four of the eight thumbnails are abstract placeholders
   (`proj-campaign/leadgen/branding/digital.jpg`). Drop real screenshots in at
   the same paths and they appear automatically.

3. **Legal pages.** `privacy.html` and `terms.html` are starting templates, not
   legal advice — have them reviewed before publishing.

## Structure

```
assets/css/style.css   all styling (colours live in :root at the top)
assets/js/main.js      header/footer, nav, filters, forms, animations
assets/img/            images
serve.py               Python local server
start-server.ps1       PowerShell local server (no installs needed)
```

The header and footer are generated by `main.js` so every page stays in sync —
edit them once in `buildHeader()` / `buildFooter()`. Each page also contains a
plain-HTML nav underneath, which shows if JavaScript is ever unavailable.

## Hosting

Upload the whole folder to any static host (Netlify, Vercel, GitHub Pages,
Hostinger, cPanel). No configuration needed. `index.html` is the home page.
