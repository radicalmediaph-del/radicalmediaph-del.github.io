Settings

These keys are kept only in this browser on this device. Nobody who opens this page elsewhere can save or post without them.

Website key Not connected

Lets this page save your trips to radicalmediaph.com. It is a GitHub access key that can only change this one website.

How to get the key (once, about 2 minutes)
  1. Open github.com/settings/personal-access-tokens/new while signed in as radicalmediaph-del.
  2. Name it Eve back office, and set Expiration to the longest it allows.
  3. Under Repository access, choose Only select repositories and pick radicalmediaph-del.github.io.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, paste it above and press Connect.

Facebook page Not connected

Lets this page post to your Eve Wanderlust page and, through it, to Instagram.

Instagram: Not connected It connects by itself when @eve.wanderlust.ph is a Professional account linked to the Eve Wanderlust page.

How to get the page token (once)
  1. Open developers.facebook.com/apps and create an app (type Business), named Eve back office.
  2. Open Graph API Explorer, pick that app, then Get Page Access Token and tick pages_manage_posts, pages_read_engagement, pages_show_list, instagram_basic and instagram_content_publish.
  3. Choose the Eve Wanderlust page in the "User or Page" box and copy the token.
  4. To stop it expiring in an hour, paste it into the Access Token Debugger and press Extend Access Token; use the new token.
  5. Paste it above and press Connect. The page name appears when it works, and the Instagram account if it is linked.
  6. Instagram says "Not linked"? In the Instagram app go to Settings → Account type and tools → Switch to professional account, then on the Eve Wanderlust Facebook page go to Settings → Linked accounts → Instagram and connect it. Press Connect here again.

YouTube Not connected

Lets this page upload the trip video to your YouTube channel as a Short. You sign in with Google each time you post; nothing is stored but the ID below.

How to get the client ID (once, about 5 minutes)
  1. Open console.cloud.google.com/projectcreate with the Google account that owns your YouTube channel. Name the project Eve back office and press Create.
  2. Open YouTube Data API v3 and press Enable.
  3. Open Google Auth Platform, press Get started, name the app Eve back office, pick your email, choose External, and finish. Under Audience, add your own Gmail as a Test user.
  4. Under Clients, press Create client, choose Web application, and under Authorised JavaScript origins add https://radicalmediaph.com. Press Create.
  5. Copy the Client ID, paste it above and press Connect. Pick your channel when Google asks. If Google says the app isn't verified, press Continue; it's your own app.
